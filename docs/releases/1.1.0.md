# DepthWall 1.1.0

More space imagery, car wallpapers and phone-sized exports, with depth controls available directly in Settings. Android 12 or newer is required. The default display profile is the **OnePlus 7T Pro McLaren: 1440 × 3120**.

## What's new

- **More sources:** paginated NASA originals and SFW Wallhaven, plus Wikimedia and ESA / ISRO / JAXA / CSA collections through Commons. Credits and source links stay with saved images.
- **No app download-count quota:** continue through search pages and save images without a DepthWall account or subscription. Providers can still limit requests, and image rights and resource limits apply.
- **4K and website import:** filter by verified source dimensions, or paste an accessible HTTPS wallpaper page/direct image link. Browser shortcuts include ESA, ESO, Hubble, Webb and Wallpaper Abyss. Some websites require a browser download followed by local import.
- **Cars and AMOLED themes:** five new 2160 × 4680 originals, including two sports-car illustrations, plus Papaya, Space blue and AMOLED monochrome interface palettes.
- **Phone-friendly exports:** preserve original static image bytes, crop to the phone display, or export up to 2160 × 4680 for the 7T Pro aspect ratio. Smaller source crops are never enlarged into claimed 4K detail.
- **crDroid native AOD setup:** direct access to system AOD settings, read-only compatibility observations and a copyable report for the OnePlus 7T Pro McLaren **4G (`hotdog`)**. Wallpaper and preview motion pause while their display is ambient or off. This does not enable privileged wallpaper imagery during AOD.
- **Depth in Settings:** persistent depth/parallax/clock defaults, explicit updates to active DepthWall depth scenes, and a Settings entry in Android's live wallpaper picker.

## Installation and upgrades

Use the APK asset attached to this repository's release. An in-place update requires the same signing identity as the installed DepthWall app; a debug APK or a new release key cannot replace an existing personal release. Keep the installed app if Android reports a signature mismatch, and obtain a build signed with its original key. Uninstalling removes its private data.

Database schema 2 adds image dimensions while retaining existing favourites and saved image paths. See [installation instructions](../INSTALL.md) for export profiles, depth controls and source builds.

## Validation and limits

Build checks passed: optimized release assembly with R8/resource shrinking, **46 unit tests in each of the debug and release variants**, Android lint with **0 errors / 41 warnings** in each variant, debug APK assembly, and Android test APK assembly. The unsigned release output also passed ZIP/native-library alignment checks; an installable update still requires the original signing key. The test APK includes settings-persistence, database-migration and export-quality checks; instrumentation tests were compiled but not run because no Android device or emulator was connected. Physical OnePlus testing and the v1.1.0 upgrade path remain pending.

NASA, Commons agency searches, Wallhaven and representative space-gallery/wallpaper pages were checked live. Source services can change, and website import cannot extract an image from every page or bypass login/paywall/anti-bot requirements.

Foreground depth requires layers or a mask and uses DepthWall's own wallpaper clock. Android/crDroid controls its native lock-screen clock, system theme and AOD. Historical third-party Xiaomi/HyperOS port limitations remain documented in the [compatibility report](../COMPATIBILITY.md).
