# DepthWall 1.5.1

Fixes the AOD module making the phone look rooted to apps that hide from Magisk.

Installs as a normal update over 1.5.0 (same signing key). Library and settings are kept.

## The AOD module no longer shows up in other apps

The 1.5.0 module turned on crDroid's "wallpaper on AOD" flag with an overlay on the Android framework. Android loads framework overlays into the starting process of every app, before Magisk's DenyList or Shamiko can hide anything, and crDroid's built-in hiding does not cover it. Apps that check for root, such as DigiYatra, could see that overlay coming from the Magisk module folder and reported the phone as rooted.

1.5.1 sets the same switch inside SystemUI instead (`config_dozeSupportsAodWallpaperOverride`). Only SystemUI loads that overlay, so the DenyList hides the module from other apps as usual. AOD should behave the same.

To update:
1. Install DepthWall 1.5.1 over 1.5.0.
2. Rebuild the module from the APK you installed: `python3 tools/build_aod_module.py app/build/outputs/apk/release/app-release.apk`.
3. Flash `artifacts/DepthWall-AOD-module.zip` in Magisk or KernelSU over the old module, then reboot. The old framework overlay is removed with it.
4. In DepthWall, open **Settings → Always-on display → Set up & check AOD**. **ROM shows wallpapers on AOD** should be on.

To check what an app can see, open it, then run `tools/integrity_report.sh SERIAL artifacts/integrity` on your computer. `app-mappings.txt` should list no DepthWall lines for that app or for zygote. Magisk asks once to allow root for Shell.

The SystemUI overlay has not yet been run on the emulator or the phone. If **ROM shows wallpapers on AOD** stays off after flashing, include the report's `overlays.txt` in the bug report.

## Not fixed by this release

Some apps decide on Google Play Integrity alone. On Android 13 and later its device verdict needs a locked bootloader and a certified manufacturer image, so an unlocked crDroid phone only gets the basic verdict, with or without the module. The Claude app has checked this at sign-in since late October 2026; use claude.ai in the browser instead.
