# DepthWall 1.2.0-preview.1

An installable test build of the restart fixes for Super wallpapers and the new "Best for your phone" collection. Android 12 or newer is required.

## Install the preview

Download **DepthWall-1.2.0-preview.1.apk** from this release, open it on the phone and launch **DepthWall Preview**. It installs alongside the stable DepthWall app with package ID `dev.srimi.depthwall.preview`. It has its own library and preferences and does not copy data from the stable app.

The APK is optimized and non-debuggable, but it is signed with the release runner's **development certificate**, not the production identity. It cannot update the stable app. It also cannot update an installed 1.1.0 preview that was signed on another runner: if Android reports a conflict, uninstall **DepthWall Preview** first (this removes only the preview's own data), then install this APK. Apply a DepthWall Preview wallpaper from the preview app to test it.

## Included changes

- **Black or frozen after a restart.** DepthWall's live wallpaper retries its graphics surface if it fails during start-up, rebuilds it if it is lost, and draws black for an unreadable depth layer instead of stalling. Applying the same scene again now restarts it.
- **Xiaomi/HyperOS ports.** A port that is your current wallpaper shows **Black or frozen? Restart it** on its card. DepthWall switches that screen to black, offers a force stop, and reopens the picker for a fresh start. It also warns when Home and Lock use two scenes from the same pack.
- **Best for your phone.** A new Explore row with eleven 2160 × 4680 papaya, carbon and space originals for the 1440 × 3120 panel, plus favourites from the existing set and the live Sun scene. New **Papaya Edition** filter.
- Lock-only rotation no longer replaces a live lock screen that shares the home wallpaper.

Full details are in the [1.2.0 notes](../releases/1.2.0.md).
