# DepthWall 1.5.0

Adds super wallpapers on Always-On Display for rooted phones, a StandBy charging clock and eleven clock faces.

**Uninstall DepthWall first.** 1.5.0 uses a new signing key because the key behind 1.2.0–1.4.0 is not available, so Android cannot install it over an earlier version. Favourites, downloads, imports and settings are not carried over. Later versions update normally.

## Super wallpapers on AOD

Android shows a live wallpaper during AOD only if the app holds a permission that crDroid gives to system apps alone, and only while crDroid's "wallpaper on AOD" setting is on. The DepthWall AOD module for Magisk or KernelSU installs DepthWall as a system app, turns that setting on once, and lets DepthWall switch it. To set it up:
1. Uninstall the old DepthWall, then install DepthWall 1.5.0.
2. Build the module on your computer: `python3 tools/build_aod_module.py app/build/outputs/apk/release/app-release.apk`. Use the same signed APK you installed.
3. Flash `artifacts/DepthWall-AOD-module.zip` in Magisk or KernelSU and reboot.
4. In DepthWall, open **Settings → Always-on display → Set up & check AOD**. When the checklist is ready, tap **Apply AOD wallpaper** and choose **Lock screen** or **Home and lock screens**.
5. Turn on Always-On Display in crDroid's settings and lock the phone.

On AOD the planet shrinks to a soft disc on true black below crDroid's clock; Android adds its own dimming and blur. Each time AOD starts it moves a few pixels, against burn-in. Press power and the planet zooms back to its lock-screen orbit; unlock and it lands on the terrain, as before. DepthWall draws one still frame per AOD session: no animation, sensors or DepthWall clock run while the screen sleeps. crDroid's AOD clock and notifications stay on top.

- DepthWall updates must be signed with the same key as the module's copy.
- To try it without your release key, build the module from the preview APK (`./gradlew :app:assemblePreview`, then `python3 tools/build_aod_module.py app/build/outputs/apk/preview/app-preview.apk`). It installs **DepthWall Preview** as the system app, next to your normal DepthWall; apply the AOD wallpaper from DepthWall Preview.
- Removing the module returns DepthWall to a normal app. The AOD wallpaper then turns off on its own.
- Without the module nothing changes: rendering stops while the screen sleeps, as in 1.4.0.

## StandBy

A full-screen clock on the charger, like iPhone StandBy.
1. Open **Home → StandBy** (or **Settings → StandBy settings**), pick a face and options, then tap **Screen saver**.
2. Choose **DepthWall StandBy** and set **When to start** to **While charging**.
3. Put the phone on its side on the charger.

In landscape, swipe sideways between three pages: the clock, your DepthWall planet, and widgets. Swipe up or down to change the face; on the widgets page, swipe the right half to change the widget. Portrait shows a nightstand clock with date, battery and next alarm. Long-press to leave. **Save & try** and the Quick Settings tile open StandBy any time.

Night mode (Auto by default) uses the light sensor: in a dark room everything turns deep red and the screen dims. StandBy draws on true black, redraws at most once a second, shifts a few pixels each minute and dims after 30 minutes without a touch. It runs only while the screen saver is showing.

## Clock faces

Digital, Minimal, Analogue, Bold, Float, Solar, World, Flip, Word, Dot matrix and Gauge. All eleven work in StandBy and as the clock layer in depth wallpapers.
