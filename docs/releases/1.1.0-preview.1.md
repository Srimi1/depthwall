# DepthWall 1.1.0-preview.1

An installable test build of the new wallpaper collections, phone export profiles, depth settings and crDroid AOD setup. Android 12 or newer is required.

## Install the preview

Download **DepthWall-1.1.0-preview.1.apk** from this release, open it on the phone and launch **DepthWall Preview**. It installs alongside the stable DepthWall app with package ID `dev.srimi.depthwall.preview`. Keep your existing app installed: this preview has its own library and preferences and does not automatically copy stable-app data.

The APK is optimized and non-debuggable, but uses a **development signing certificate**, not the v1.0.1 production identity. It is a separate test application, not an in-place update. Future preview updates also require the same preview signing identity. The normal 1.1.0 update still requires the original production key.

## Included features

- Paginated NASA originals, SFW Wallhaven and Wikimedia, with ESA / ISRO / JAXA / CSA collections through Commons. There is no app download-count quota or subscription; provider limits, image rights and storage limits still apply.
- A 4K source filter and import from accessible HTTPS wallpaper pages or direct image links, plus shortcuts to space galleries and Wallpaper Abyss. Some sites require a browser download followed by local import.
- Five new 2160 × 4680 car and theme originals, plus Papaya, Space blue and AMOLED monochrome interface palettes.
- OnePlus 7T Pro McLaren exports: original files, 1440 × 3120 phone crops, or portrait output up to 2160 × 4680. Smaller source crops are not enlarged into claimed 4K detail.
- Persistent depth, parallax and wallpaper-clock controls in Settings and Android's live wallpaper picker.
- **Settings → Set up & check AOD** for the OnePlus 7T Pro McLaren **4G (`hotdog`)**, with system AOD settings, read-only observations and a copyable build report. Wallpaper and preview motion pause while their display is ambient or off.

## Validation and limits

The underlying 1.1.0 debug and release variants passed 46 unit tests each and lint with 0 errors / 41 warnings. Refer to this prerelease's attached verification evidence for checks on the actual preview APK.

**Physical-phone testing remains pending**, including installation and sleep → AOD → wake on the user's exact crDroid Android 17 build. crDroid controls its clock/notification AOD. Wallpaper imagery during AOD requires privileged ROM integration and is not enabled by this APK; DepthWall's wallpaper clock is separate from the system clock.

Website import cannot extract images from every site or bypass login, paywalls or anti-bot checks. Existing third-party Xiaomi/HyperOS port limitations still apply. See [installation](../INSTALL.md), [AOD details](../AOD_AND_EMULATOR.md) and [compatibility](../COMPATIBILITY.md).
