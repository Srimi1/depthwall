# DepthWall 1.3.0

A redesigned DepthWall. It installs as a normal update over 1.2.0 and keeps your favourites, downloads and settings. Android 12 or newer is required.

## What's new

- **New look.**
  - Five tabs at the bottom: **Home**, **Live**, **Browse**, **Depth** and **Library**.
  - A larger header that shows the version you're running.
  - Poster cards with titles on the artwork.
  - A refreshed true-black palette.
- **Home.** A full-screen carousel of the newest originals made for the OnePlus 7T Pro's 1440 × 3120 panel, then shelves for:
  - Best for your phone;
  - Living worlds;
  - Papaya Edition;
  - Into space;
  - Depth.
- **Live wallpapers built in.** The Live tab leads with DepthWall's seven own scenes, which need no extra apps. Xiaomi/HyperOS packs are optional separate apps, so DepthWall lists only the ones you have installed. The rest sit in a collapsed **Original Xiaomi / HyperOS packs** section instead of six "Not installed" cards.
- **Browse** keeps search, categories, colours, NASA, Wikimedia, Wallhaven and website import.

The restart fixes from 1.2.0 are unchanged. If a scene is black or frozen after a restart, apply it again. For an installed HyperOS pack, use **Black or frozen? Restart it** on its card.

## Install

Download `DepthWall-1.3.0.apk` and open it. Android shows it as an update to DepthWall 1.2.0. If you still have DepthWall 1.1.0 or older, see the [1.2.0 notes](../releases/1.2.0.md): that version needs a one-time uninstall.

## Validation and limits

CI built and tested this release and checked its signature against the 1.2.0 key. Instrumentation tests were compiled but not run, and the new screens still need checking on the phone.
